## 🎯 Filosofia & Decisões de Engenharia

Em um cenário onde frameworks muitas vezes são aplicados sem necessidade, a proposta deste portfólio foi demonstrar **domínio sólido sobre a base da web**. O objetivo principal foi criar uma interface visualmente marcante ("Dark Premium"), altamente fluida e com custo zero de pacotes de terceiros.

Cada módulo foi escrito buscando o equilíbrio entre estética moderna e **SEO Técnico de precisão**, **Core Web Vitals impecáveis** e **Acessibilidade (a11y) nativa**.

---

## ✨ Destaques Técnicos & UX

- 🚀 **Performance Nativa:** Zero peso de runtimes de terceiros. Carregamento instantâneo do DOM com foco total na otimização da métrica LCP (Largest Contentful Paint).
- 🎨 **Design System com CSS Moderno:** Utilização de CSS Custom Properties (Tokens de Design), escopo modular e uso da função `clamp()` para tipografia e espaçamentos fluidos em qualquer resolução.
- 🌓 **Tema Inteligente:** Dark/Light mode com persistência em `localStorage` e sincronização imediata com a preferência do sistema operacional (`prefers-color-scheme`).
- 👁️ **Animações de Alta Frequência (60fps):** Interações de scroll controladas via `IntersectionObserver` API, garantindo movimentação suave sem travar a *main thread* do navegador.
- ♿ **Acessibilidade de Primeira Classe:** Navegação 100% funcional via teclado, focos visíveis, gerenciamento correto de estado em modais e contraste validado pelo padrão WCAG.
- 🔍 **SEO Avançado & Rich Snippets:** Meta tags dinâmicas, Open Graph completo para redes sociais e dados estruturados Schema.org (`JSON-LD Person`) para indexação no Google.

## 🚀 Como Rodar o Projeto Localmente

Por não possuir dependências de build ou pacotes pesados, o projeto roda instantaneamente em qualquer servidor estático:

1. **Clone o repositório:**
```bash
git clone https://github.com/bernardo-netto/portfolio-bernardo-netto.git

```


2. **Acesse a pasta do projeto:**
```bash
cd portfolio-bernardo-netto

```


3. **Inicie o servidor local (exemplo via npx):**
```bash
npx serve .

```



*Ou abra diretamente via extensão **Live Server** no VS Code.*
